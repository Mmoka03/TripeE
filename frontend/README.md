# 프론트엔드

React + Vite로 사용자 지도와 관리자 화면을 구현함. 실행·검증 명령은 [루트 README](../README.md)에 정리했음.

## 파일 구성

| 파일                      | 역할                                         |
| ------------------------- | -------------------------------------------- |
| src/main.jsx              | 경로에 따라 사용자·관리자 화면을 지연 로드함 |
| src/App.jsx               | 도시 검색과 상세 패널 상태를 관리함          |
| src/MapView.jsx           | MapLibre 초기화·핀 병합·지도 이동을 처리함   |
| src/data.js               | 초기 도시와 인접 도시 테스트 데이터를 보관함 |
| src/admin/AdminApp.jsx    | 관리자 화면 전환과 편집 상태를 관리함        |
| src/admin/AdminFields.jsx | 공통 필드와 안전정보 입력 양식임             |
| src/admin/demoService.js  | localStorage 기반 관리자 작업 모형임         |

## 개발 시 참고

- /admin은 A/B 시연 선택으로 진입함. 실제 로그인 기능이 아님.
- 관리자 저장 키는 tripee.admin-demo.v1임. 하단 초기화 버튼은 이 시연 데이터만 교체함.
- 사진 파일은 메모리에서 미리보기하며 새로고침하면 원본 미리보기가 사라짐.
- 재진입 후 본인 잠금은 ‘편집 재개’로 가져올 수 있음. 이전 화면의 저장은 차단하고 마지막 저장본을 불러옴.
- 지도 검수 도구에서 오사카·오쓰의 핀 겹침과 상세 로딩·오류 상태를 시험할 수 있음.
- 실제 API 연결 시 시연 데이터 구조를 그대로 전송하지 않고 계약에 맞는 변환 계층을 작성할 예정임.

지도는 OpenFreeMap Positron 스타일을 사용함. 요청은 브라우저에서 제공처로 직접 전송됨. 출처 표시는 유지해야 함. 인접 도시의 좌표 출처는 src/data.js에 기록했음.
