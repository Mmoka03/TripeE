# 프로젝트 범위와 진행 상태

백엔드 PR #5가 `develop`에 병합된 상태를 기준으로 작성함.

## 목표와 팀

목적지를 정하기 전 해외 도시를 탐색하는 한국어 사용자를 대상으로 함. 도시의 사진·대표 경험·여행 정보·안전정보와 출처를 한 화면에서 제공할 예정임.

A와 B의 2인 프로젝트임. A는 와이어프레임과 GitHub 준비를 담당하며 DB 설계 경험이 있음. B는 React·Spring을 포함한 전반적인 개발 경험이 상대적으로 많음. 세부 구현 담당은 추가 조율할 예정임. 전체 일정은 약 7주로 논의했음.

## 범위

- 초기 도시는 나폴리·교토·베이징이며 개발 상황에 따라 변경 가능함.
- 태그는 도시 단위로 적용하며 이름은 한국어·영문을 관리함.
- 대표 경험은 여러 개 저장하고 선정 항목 중 최대 3개를 표시함.
- 사진은 여러 장 저장하되 한 장씩 슬라이드로 표시함.
- 안전정보는 출처·확인 상태·적용 범위로 표현함. 미확인은 안전함을 의미하지 않음.
- 도시별 일반 초안은 하나이며 전체 단위로 게시함. 안전정보는 별도로 게시할 수도 있음.
- 비공개는 데이터를 유지함. 삭제는 업무 데이터를 제거하고 독립 감사 이력을 남김. 복원 기능은 범위에 포함하지 않음.
- 비교 기능, 실시간 맛집·SNS 수집, 회원가입은 현재 MVP 범위에서 제외했음.

## 기술과 구현 상태

| 구분           | 현재 상태                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------- |
| React·Vite     | 사용자·관리자 로컬 시연 구현했음                                                            |
| MapLibre GL JS | OpenFreeMap Positron 기본 스타일을 연결했음                                                 |
| Spring Boot    | 공개 조회·관리자 API 구현했음. 실제 프론트 연동은 남아 있음                                 |
| PostgreSQL     | 초기 DDL·앱 계정 권한·제약조건·격리 DB 통합 테스트를 작성했음                               |
| AI             | 후보 API의 입력·출력 검증을 구현했음. 제공자 연동은 미정임                                  |
| Docker·AWS     | 개발 DB Compose와 테스트용 컨테이너를 사용함. 전체 서비스 컨테이너화·AWS 배포는 후속 작업임 |

AI 입력은 등록한 출처와 사람이 제공한 본문을 사용하며 URL 자동 수집은 포함하지 않음. 후보를 관리자가 검토해 초안에 적용하는 방식임. 안전정보 자동 생성·자동 게시는 제외했음.

## 문서 기준

DB의 물리 제약조건은 `backend/db/schema.sql`과 [DB 제약조건](backend/db-constraints-v1.md), API 계약은 [API 정책](backend/api-v1.md)과 [OpenAPI](backend/openapi-v1.json)를 기준으로 함. OpenAPI는 `tools/api-contract/build.mjs`에서 생성하므로 생성기를 수정한 뒤 `pnpm api:generate`를 실행함. 백엔드 문서는 [backend](backend/README.md), 테스트 명세는 [backend/testing](backend/testing/README.md)에 모음.

현재 화면은 계약의 모든 필드를 구현한 상태가 아님. 특히 안전정보 복수 항목과 실제 출처 자원 관리가 남아 있음. 서버 연동 시 계약과의 차이를 확인해야 함.

Figma 디자인 파일: https://www.figma.com/design/j8BgA2aE2QQoOxHm9QMZMN
