# 백엔드 API 구현 범위와 연결 순서

공개 지도에서 도시를 찾고 상세를 여는 흐름과 관리자 세션을 시작하는 흐름이 첫 연동 대상임. 경로의 공통 접두사는 `/api/v1`임. 전체 계약은 26개 경로와 39개 작업으로 구성됨. [API 정책](api-v1.md) · [OpenAPI](openapi-v1.json)

## 이번 연동 대상

| 순서 | 요청                   | 화면에서 사용하는 방법                                                                                                                                |
| ---- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | `GET /cities`          | 첫 지도 진입 시 `items`로 핀을 그림. 국가별 조회는 `?countryCode=JP`처럼 요청함. 좌표는 숫자, 도시 ID는 문자열로 취급함.                              |
| 2    | `GET /search?q=교토`   | 도시·국가의 한글명과 영문명을 검색함. `CITY`는 해당 도시 좌표로 이동하고, `COUNTRY`는 국가 코드로 프론트의 국가 경계를 선택함. 결과 없음은 빈 배열임. |
| 3    | `GET /cities/{cityId}` | 선택한 핀의 상세를 조회함. `PREPARING`에는 준비 중 문구, `PUBLIC`에는 게시 내용을 표시함. 비공개·삭제·없는 ID는 404로 처리함.                         |
| 4    | `GET /tags`            | 활성 태그의 코드와 한국어·영어 표시명을 읽음. 도시 상세의 태그는 상세 응답에도 포함됨.                                                                |
| 5    | `GET /admin/csrf`      | 로그인 화면 진입 시 서버 세션 쿠키와 응답의 `headerName`, `token`을 받음. 관리자 변경 요청은 같은 세션에서 해당 헤더를 보냄.                          |

DB 조회는 `postgres` 프로필을 사용함. 초기 DDL에는 여행 콘텐츠가 없으므로 목록이 비어 있을 수 있음. 상세 확인에는 조회 가능한 도시의 실제 ID가 필요함. 환경 설정과 테스트 명령은 [백엔드 실행 안내](../../backend/README.md)를 따름.

지도 핀과 검색은 같은 공개 도시 목록을 읽음. 현재 세 도시 규모에서는 그 목록에서 정확히 일치하는 이름, 앞부분 일치, 부분 일치 순으로 결과를 고른 뒤 `limit`을 적용함. 검색 키워드의 앞뒤 공백을 제외한 길이는 1~100자이고, `limit`은 1~50, 기본값은 10임. 화면은 사용자가 결과를 선택한 시점에 지도를 이동함.

## 구현 상태와 화면 연결 순서

관리자 세션의 로그인·조회·로그아웃·활동 보고와 국가·태그 사전 조회를 추가했음.
로그인은 DB의 활성 계정과 BCrypt 해시를 확인하고 세션 ID 및 CSRF 토큰을 교체함.
GET 조회는 활동 시각을 연장하지 않으며, 마지막 활동에서 한 시간이 지나면 접근을 종료함.
로그아웃 시 해당 세션의 편집 잠금을 반납함.

아래 1~5번의 백엔드 API는 구현돼 있으며, 표는 프론트 연결 순서를 나타냄.
6번 AI 후보 생성은 응답 형식과 실패 처리만 준비된 상태로 외부 AI 연동이 필요함.

| 우선순위 | 필요한 API                                                                                              | 연결 전 확인할 사항                                                                                                           |
| -------- | ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 1        | 관리자 초기 계정 준비와 로그인 화면 연동                                                                | 계정의 password_hash에는 BCrypt 해시를 저장함. CSRF 발급 뒤 로그인하고 토큰을 다시 받음. 로그인 시도 횟수 제한은 후속 보완함. |
| 2        | 관리자 도시 목록·생성·조회 및 편집 잠금 획득·조회·갱신·반납, 초안 생성·조회·저장·폐기                   | 두 편집 창이 경쟁할 때 잠금 토큰, ETag와 `If-Match` 오류를 화면에서 안내하고 다시 조회하는지 확인함.                          |
| 3        | 사진 등록·조회와 공개 파일 전송 `GET /media/photo-assets/{assetId}`, 출처 등록·조회, 초안 미리보기·게시 | 상세의 사진 URL을 연결함. 대표 경험, 사진 대체 텍스트, 검토된 출처를 갖춘 교토 초안을 게시해 지도에서 확인함.                 |
| 4        | 안전정보 독립 게시와 충돌 재검토                                                                        | 일반 초안의 안전 버전과 독립 게시 버전이 달라졌을 때 충돌을 감지하고 재검토 결과를 저장함.                                    |
| 5        | 도시 비공개·삭제, 과거 버전과 감사 이력 조회                                                            | 공개 지도에서 노출이 중단되는 시점과 삭제 뒤 보존되는 감사 스냅샷을 확인함.                                                   |
| 6        | 대표 경험 AI 후보 생성                                                                                  | 관리자 입력과 등록 출처로 후보를 반환하고, 담당자가 선택한 뒤 기존 초안 저장 API로 반영함.                                    |
