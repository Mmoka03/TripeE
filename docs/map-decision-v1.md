# 지도 설정

MapLibre GL JS를 지도 표시 라이브러리로 채택했음. 현재 버전은 frontend/package.json과 lockfile로 고정함.

## 현재 구성

- OpenFreeMap Positron 스타일을 연결했음. VITE_MAP_STYLE_URL 환경변수로 교체 가능함.
- 기본 지도 지명은 숨기고 대륙명과 도시 핀을 별도로 표시함.
- 핀 병합은 화면상의 픽셀 거리를 기준으로 처리함. 지리적 행정 구역 단위의 군집은 아님.
- 도시 선택·패널 열기와 닫기만으로 지도 위치를 이동시키지 않음. 검색 결과 선택 시에 이동함.
- OpenFreeMap·OpenMapTiles·OpenStreetMap 출처 표시는 유지함.
- 국가 검색 범위는 프론트의 임시 상수를 사용함. 최종 데이터는 검증할 예정임.

## 후속 확인

운영용 제공처의 이용 조건·요금·요청 제한과 모바일 기기 성능은 배포 준비 시 확인할 예정임. MapLibre 채택과 지도 공급원의 최종 운영 채택은 별개임.
